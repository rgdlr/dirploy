Built for Safety and Simplicity

Designed around strict invariants to protect your public user site.

🛡️

Subdirectory Isolation

Each deployment owns strictly its destination folder. Sibling projects and root files are never touched.

⚡

Zero Runtime Dependencies

Zero third-party packages in production. Built entirely on standard Node.js APIs for instant npx execution.

🔒

Private Source, Public Output

Keep your source code private while publishing compiled artifacts publicly without giving access to the source repository.

⚡

Local Cache & Parent Detection

Clones using existing local user site repos as reference when present, minimizing network transfers and clone time.

🌐

Custom Domain & CNAME

Seamlessly detects or provisions custom CNAME records and disables Jekyll builds via automatic .nojekyll.

🔄

Push Retry & Conflict Resilience

Safely retries on non-fast-forward rejections with backoff without performing destructive force-pushes.

🚫

Path Traversal Protection

Rejects directory escapes (../) and repo root overwrites before any filesystem mutation occurs.

👁️

Dry Run Previews

Inspect exact file counts (added, updated, removed) with --dry-run without committing or pushing anything.

🔍

Subpath Base URL Check

Inspects your build for broken root-relative asset URLs and warns you before broken links hit production.

⚙️

Config Wizard (`dirploy init`)

Bootstrap your project setup in seconds with interactive or flag-based configuration generation.

Quick Start

Publish manually, configure project defaults, or automate via GitHub Actions.

# Bootstrap configuration file:
npx dirploy init

# Publish ./dist to https://<owner>.github.io/<project>/
npx dirploy ./dist

# Publish to a custom subpath:
npx dirploy ./dist --path my-project

# Preview changes safely without pushing:
npx dirploy ./dist --dry-run

Run npx dirploy init or create dirploy.config.json in your project root:

{
	"$schema": "https://raw.githubusercontent.com/rgdlr/dirploy/main/schema.json",
	"source": "dist",
	"path": "my-project",
	"branch": "main",
	"clean": true,
	"nojekyll": true
}

Deploy automatically on push to main in GitHub Actions:

name: Deploy
on:
	push:
		branches: [main]

permissions:
	contents: write

jobs:
	deploy:
		runs-on: ubuntu-latest
		steps:
			- uses: actions/checkout@v4
			- uses: actions/setup-node@v4
				with:
					node-version: 22
			- run: npm ci
			- run: npm run build
			- run: npx dirploy ./dist
				env:
					GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
					# For cross-repo deployments: DIRPLOY_TOKEN: ${{ secrets.DIRPLOY_TOKEN }}

Configure your bundler base URL so assets load properly under subdirectories:

vite.config.ts:
export default defineConfig({
	base: './',
})

astro.config.mjs:
export default defineConfig({
	base: '/my-project/',
})

next.config.js:
module.exports = {
	output: 'export',
	basePath: '/my-project',
}

Use Dirploy programmatically in your build scripts or tools:

import { deploy } from 'dirploy'

const result = await deploy({
	sourceDirectory: './dist',
	repository: 'username/username.github.io',
	branch: 'main',
	destinationPath: 'my-project',
	dryRun: false,
})

console.log(`Published at: ${result.url}`)
